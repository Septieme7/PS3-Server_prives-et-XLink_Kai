01

Guide complet : Jouer en ligne sur PS3 OFW/CFW via XLink Kai et serveurs privés

Ce guide détaille les méthodes pour jouer en réseau sur PS3 lorsque les serveurs officiels sont fermés. Il couvre XLink Kai (tunneling LAN), les serveurs privés via DNS, et les émulateurs de serveurs sur PC.

ℹ️

Important : Ce guide s'applique aux PS3 OFW (firmware officiel) et CFW/HFW.
Le CFW n'est pas obligatoire pour :

  • XLink Kai (si le jeu supporte le LAN/System Link natif)
  • La redirection DNS vers la plupart des serveurs privés

Le CFW/HFW devient nécessaire pour :

  • Les patchs EBOOT personnalisés
  • Les outils comme ezDNS, webMAN, etc.
  • Certains émulateurs de serveurs sur PC (EA Plasma/Arcadia, etc.)
⚠️

Rappel important : Toutes les PS3 doivent avoir exactement la même version du jeu (mise à jour, DLC) pour jouer ensemble.

🔄

Mise à jour : Ce guide intègre la liste des serveurs custom/revival, leurs DNS et les jeux associés. Pour les serveurs DNS custom, utilise l'IP indiquée comme DNS primaire, puis 1.1.1.1 ou 8.8.4.4 comme DNS secondaire, sauf indication contraire.

03

XLink Kai : Configuration complète

XLink Kai est un service de tunneling LAN qui permet de jouer à des jeux PS3 en réseau local à travers Internet. Il fonctionne avec 105 jeux PS3 vérifiés comme supportant le LAN.

ℹ️

Compatibilité OFW : XLink Kai fonctionne aussi sur PS3 OFW. Il exploite le mode LAN/System Link du jeu. Aucun CFW n'est requis si le jeu propose ce mode.

Matériel requis

  • Une PS3 (OFW ou CFW)
  • Un PC/Mac/Raspberry Pi
  • 1 ou 2 câbles Ethernet selon la configuration
  • Une connexion Internet
  • Un compte XLink Kai (gratuit)

Étape 1 : Créer un compte XLink Kai

  1. Va sur teamxlink.co.uk
  2. Clique sur "Sign Up" et remplis le formulaire
  3. Vérifie ton adresse e-mail et accepte la politique de collecte de données (RGPD)
  4. Lis et accepte l'Acceptable Use Policy

Étape 2 : Installer XLink Kai sur le PC

  1. Télécharge la dernière version de XLink Kai depuis teamxlink.co.uk/downloads.php
  2. Installe le logiciel sur ton PC
  3. Lance XLink Kai et connecte-toi avec ton compte

Étape 3 : Configuration réseau (2 méthodes)

Méthode A : Configuration entièrement filaire (recommandée)

C'est la méthode offrant la latence la plus faible et la connexion la plus stable.

Internet → Routeur ← PC (XLink Kai)
              ↖ PS3
  1. Relie le PC et la PS3 au même routeur via des câbles Ethernet
  2. Dans XLink Kai, va dans "Configure Kai" et sélectionne la carte réseau connectée à la PS3
  3. Configure la PS3 en réseau automatique (DHCP)

Méthode B : Configuration semi-sans fil

Si le câblage complet est impossible, le PC peut être en Wi-Fi mais doit être connecté à la PS3 par Ethernet.

Internet → Box Wi-Fi → PC (XLink Kai, Wi-Fi)
                    ↖ PS3 (Ethernet)
  1. Connecte le PC à la box en Wi-Fi
  2. Relie la PS3 au PC avec un câble Ethernet (ou un adaptateur USB-Ethernet si le PC n'a pas de port Ethernet)
  3. Dans XLink Kai, sélectionne la carte réseau Ethernet (celle connectée à la PS3)

Étape 4 : Configuration de la PS3

  1. Allume XLink Kai sur le PC AVANT la PS3 (très important)
  2. Allume la PS3 et va dans Paramètres → Paramètres réseau → Paramètres de connexion réseau
  3. Sélectionne "Personnalisé" puis "Automatique" pour l'adresse IP et le DHCP
  4. Pour le DNS, tu peux laisser en automatique ou utiliser un DNS public comme 1.1.1.1
  5. Sauvegarde et teste la connexion
  6. Tu dois obtenir une erreur DNS (80710102) — c'est normal et attendu ! Cela signifie que la PS3 ne contacte pas les serveurs PSN et que XLink Kai prend le relais
💡

Dépannage : problèmes de connexion ou freezes en multijoueur

Si un jeu rencontre des problèmes de connexion avec d'autres joueurs ou des freezes anormaux, il est possible que sa mise à jour (patch) soit corrompue ou entre en conflit avec ta configuration réseau actuelle.

Solution temporaire :

  1. Va dans Jeu > Utilitaires de données de jeu sur le XMB.
  2. Localise le fichier du jeu concerné et supprime-le (cela efface le patch et les données installées, mais pas tes sauvegardes).
  3. Relance le jeu sans te connecter au PSN pour vérifier si le problème est résolu.

⚠️ Important : cette manipulation désactive le jeu en ligne tant que la mise à jour n'est pas réinstallée. Pour rejouer en multijoueur, tu devras retourner sur le PSN et retélécharger le patch. Ne supprime jamais un fichier dans "Utilitaire de données sauvegardées (PS3)" — cela effacerait ta progression.

Étape 5 : Lancer une partie

  1. Avec XLink Kai lancé et connecté sur le PC
  2. Allume la PS3 (elle doit afficher l'erreur DNS)
  3. Lance un jeu supportant le LAN
  4. Dans XLink Kai, navigue dans les "Arenas" (salons) et rejoins une session pour ton jeu
  5. D'autres joueurs du monde entier apparaîtront dans le jeu comme s'ils étaient sur ton réseau local

Ouverture des ports

XLink Kai utilise le port 30000 (TCP et UDP) par défaut. Ouvre ce port sur ton routeur pour le PC exécutant XLink Kai.

  • Port : 30000 (TCP et UDP)
  • Protocole : Les deux (UDP & TCP)

Astuces XLink Kai

  • Vérifie que ton réseau est "Reachable" : Dans XLink Kai, clique sur la loupe. Le diagnostic doit afficher "YES" pour Network Reachable
  • Utilise XLink Kai en mode administrateur sur Windows (clic droit → Exécuter en tant qu'administrateur)
  • Désactive l'auto-save dans les jeux de course comme F1 2010 pour éviter les conflits
  • Utilise un câble Ethernet direct entre PC et PS3 si possible pour une stabilité maximale
04

Serveurs privés via DNS (Online uniquement)

Pour les jeux "Online uniquement" qui n'ont pas de mode LAN, la méthode la plus courante est la redirection DNS. Ta PS3 est redirigée vers un serveur de remplacement qui imite les réponses des serveurs officiels.

ℹ️

Compatibilité OFW/CFW : La redirection DNS fonctionne sur PS3 OFW et CFW.
Aucun CFW n'est requis pour la redirection DNS seule.
Si le serveur demande un patch EBOOT ou une version modifiée du jeu, il faudra passer en CFW/HFW.

Comment ça marche

Le jeu PS3 contacte des adresses comme cod7-ps3-lobby.demonware.net. En modifiant le DNS de la console pour qu'il pointe vers un serveur privé, tu rediriges ces requêtes vers un serveur de remplacement.

Configuration DNS sur PS3

  1. Va dans Paramètres → Paramètres réseau → Paramètres de connexion réseau
  2. Sélectionne "Personnalisé" puis "Manuel" pour les paramètres DNS
  3. Entre les adresses DNS du serveur privé que tu souhaites utiliser

Exemple pour Unreal Tournament 3 :

  • DNS Primaire : 15.204.233.35
  • DNS Secondaire : 1.1.1.1 (ou n'importe quel DNS public comme fallback)
💡

Astuce CFW : Avec le CFW, tu peux utiliser ezDNS, une application PS3 qui permet de sauvegarder et basculer rapidement entre plusieurs profils DNS pour différents jeux. Tu peux aussi utiliser des commandes webMAN comme /netstatus.ps3?dns1=<ip> pour changer le DNS rapidement.

07

Configuration LAN entre deux PS3 (rappel)

Pour jouer en LAN local (sans Internet), voici la configuration de base :

  1. Connexion : Relie les deux PS3 à un routeur Gigabit avec des câbles Ethernet Cat5e ou Cat6
  2. Réseau : Laisse les PS3 en Automatique (DHCP) ou attribue des IP fixes
  3. Version du jeu : Les deux PS3 doivent avoir exactement la même version (mise à jour, DLC)
  4. Mode LAN : Dans le menu multijoueur, cherche "LAN", "System Link" ou "Réseau local"

Avertissements et précautions

  • Risque de bannissement PSN : L'utilisation de serveurs non officiels ou de XLink Kai peut, dans de rares cas, entraîner un bannissement du PlayStation Network. Ce risque existe aussi en OFW si vous vous connectez au PSN officiel ou à des services non officiels. Restez prudent.
  • Communauté et maintenance : Ces serveurs sont gérés par des passionnés. Leur disponibilité dépend de la communauté.
  • Compatibilité : Tous les jeux ne sont pas supportés. Vérifie les listes de compatibilité avant de commencer.
  • CFW/HFW et jeux : L'utilisation de CFW/HFW pour jouer en ligne doit être faite avec prudence. Évite de te connecter au PSN officiel avec un CFW pour éviter les risques.
  • OFW : La redirection DNS seule ne nécessite pas de CFW, mais certains serveurs peuvent demander des patchs EBOOT ou des fichiers modifiés.
