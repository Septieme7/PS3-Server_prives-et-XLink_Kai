Complete Guide: Playing Online on PS3 OFW/CFW via XLink Kai and Private Servers

This guide details the methods to play online on PS3 when the official servers are shut down. It covers XLink Kai (LAN tunneling), private servers via DNS, and server emulators on PC.

ℹ️

Important: This guide applies to PS3 OFW (official firmware) and CFW/HFW.
CFW is not required for:

  • XLink Kai (if the game supports native LAN/System Link)
  • DNS redirection to most private servers

CFW/HFW becomes necessary for:

  • Custom EBOOT patches
  • Tools like ezDNS, webMAN, etc.
  • Some PC server emulators (EA Plasma/Arcadia, etc.)
⚠️

Important reminder: All PS3 consoles must have exactly the same version of the game (update, DLC) to play together.

🔄

Update: This guide includes the list of custom/revival servers, their DNS and associated games. For custom DNS servers, use the listed IP as the primary DNS, then 1.1.1.1 or 8.8.4.4 as the secondary DNS, unless stated otherwise.

03

XLink Kai: Complete Setup

XLink Kai is a LAN tunneling service that lets you play PS3 games in a local network over the Internet. It works with 105 PS3 games verified as supporting LAN.

ℹ️

OFW compatibility: XLink Kai also works on OFW PS3. It leverages the game's LAN/System Link mode. No CFW required if the game offers this mode.

Required hardware

  • A PS3 (OFW or CFW)
  • A PC/Mac/Raspberry Pi
  • 1 or 2 Ethernet cables depending on the setup
  • An Internet connection
  • An XLink Kai account (free)

Step 1: Create an XLink Kai account

  1. Go to teamxlink.co.uk
  2. Click "Sign Up" and fill out the form
  3. Verify your email address and accept the data collection policy (GDPR)
  4. Read and accept the Acceptable Use Policy

Step 2: Install XLink Kai on the PC

  1. Download the latest XLink Kai version from teamxlink.co.uk/downloads.php
  2. Install the software on your PC
  3. Launch XLink Kai and sign in with your account

Step 3: Network configuration (2 methods)

Method A: Fully wired setup (recommended)

This is the method offering the lowest latency and the most stable connection.

Internet → Router ← PC (XLink Kai)
             ↖ PS3
  1. Connect the PC and PS3 to the same router via Ethernet cables
  2. In XLink Kai, go to "Configure Kai" and select the network adapter connected to the PS3
  3. Configure the PS3 as automatic network (DHCP)

Method B: Semi-wireless setup

If full wiring is not possible, the PC can be on Wi-Fi but must be connected to the PS3 via Ethernet.

Internet → Wi-Fi Box → PC (XLink Kai, Wi-Fi)
                     ↖ PS3 (Ethernet)
  1. Connect the PC to the box via Wi-Fi
  2. Connect the PS3 to the PC with an Ethernet cable (or a USB-Ethernet adapter if the PC has no Ethernet port)
  3. In XLink Kai, select the Ethernet adapter (the one connected to the PS3)

Step 4: PS3 configuration

  1. Start XLink Kai on the PC BEFORE the PS3 (very important)
  2. Turn on the PS3 and go to Settings → Network Settings → Internet Connection Settings
  3. Select "Custom" then "Automatic" for IP address and DHCP
  4. For DNS, you can leave it automatic or use a public DNS such as 1.1.1.1
  5. Save and test the connection
  6. You should get a DNS error (80710102) — this is normal and expected! It means the PS3 is not contacting PSN servers and XLink Kai is taking over
⚠️

Warning: If you have game updates installed on the PS3 hard drive, you may not be able to connect with other players. Go to "Game Data Utility" and delete updates for the affected games.

Step 5: Start a game

  1. With XLink Kai running and connected on the PC
  2. Turn on the PS3 (it should display the DNS error)
  3. Launch a game supporting LAN
  4. In XLink Kai, browse the "Arenas" (rooms) and join a session for your game
  5. Other players from around the world will appear in the game as if they were on your local network

Port forwarding

XLink Kai uses port 30000 (TCP and UDP) by default. Open this port on your router for the PC running XLink Kai.

  • Port: 30000 (TCP and UDP)
  • Protocol: Both (UDP & TCP)

XLink Kai tips

  • Check that your network is "Reachable": In XLink Kai, click the magnifying glass. The diagnostic should show "YES" for Network Reachable
  • Run XLink Kai as administrator on Windows (right-click → Run as administrator)
  • Disable auto-save in racing games like F1 2010 to avoid conflicts
  • Use a direct Ethernet cable between PC and PS3 if possible for maximum stability

Private Servers via DNS (Online only)

For "Online only" games that have no LAN mode, the most common method is DNS redirection. Your PS3 is redirected to a replacement server that mimics the official server responses.

ℹ️

OFW/CFW compatibility: DNS redirection works on OFW and CFW PS3.
No CFW required for DNS redirection alone.
If the server requires an EBOOT patch or a modified version of the game, you will need to switch to CFW/HFW.

How it works

The PS3 game contacts addresses like cod7-ps3-lobby.demonware.net. By changing the console's DNS to point to a private server, you redirect these requests to a replacement server.

DNS configuration on PS3

  1. Go to Settings → Network Settings → Internet Connection Settings
  2. Select "Custom" then "Manual" for the DNS settings
  3. Enter the DNS addresses of the private server you want to use

Example for Unreal Tournament 3:

  • Primary DNS: 15.204.233.35
  • Secondary DNS: 1.1.1.1 (or any public DNS as fallback)
💡

CFW tip: With CFW, you can use ezDNS, a PS3 app that lets you save and quickly switch between multiple DNS profiles for different games. You can also use webMAN commands like /netstatus.ps3?dns1=<ip> to change the DNS quickly.

07

LAN setup between two PS3 consoles (reminder)

To play on a local LAN (no Internet), here is the basic setup:

  1. Connection: Connect both PS3 consoles to a Gigabit router with Cat5e or Cat6 Ethernet cables
  2. Network: Leave both PS3 on Automatic (DHCP) or assign fixed IPs
  3. Game version: Both PS3 must have exactly the same version (update, DLC)
  4. LAN mode: In the multiplayer menu, look for "LAN", "System Link" or "Local Network"

Troubleshooting

XLink Kai issues

IssueSolution
DNS error on PS3✅ Normal! It's the sign XLink Kai is working.
"Network Not Reachable"Open port 30000 (TCP/UDP) on your router. Check that your firewall isn't blocking XLink Kai.
Can't join other playersDelete game updates in "Game Data Utility" on PS3.
PS3 doesn't detect XLink KaiStart XLink Kai BEFORE the PS3. Check the correct network adapter is selected in "Configure Kai".
High latencyUse a fully wired connection. Avoid Wi-Fi for the PS3.

DNS server issues

IssueSolution
Game won't connectCheck the DNS is correctly entered (numeric IP only, no hostname).
"PSN connection error"Some private servers require an EBOOT patch or a specific game version.
Server not respondingCheck the server status on its Discord or website.
09

Warnings and precautions

  • Risk of PSN ban: The use of unofficial servers or XLink Kai may, in rare cases, result in a PlayStation Network ban. This risk also exists on OFW if you connect to the official PSN or to unofficial services. Stay cautious.
  • Community and maintenance: These servers are run by enthusiasts. Their availability depends on the community.
  • Compatibility: Not all games are supported. Check the compatibility lists before starting.
  • CFW/HFW and games: Using CFW/HFW to play online must be done with caution. Avoid connecting to the official PSN with CFW to avoid risks.
  • OFW: DNS redirection alone does not require CFW, but some servers may require EBOOT patches or modified files.
